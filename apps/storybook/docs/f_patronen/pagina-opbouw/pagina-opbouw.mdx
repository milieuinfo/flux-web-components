# Pagina Opbouw

Bouw een pagina op met [`vl-page`](/docs/structures-page--documentatie) uit het artifact `@domg-wc/structures`, met
`vl-header-next` en `vl-footer-next` in de slots `header` en `footer`. `vl-page` zet de main content zelf in een `main`
landmark; voeg er dus geen eigen `<main>` rond toe.

## Standaard layout

Dit is de standaard layout voor applicaties. Gebruik de alternatieve "Volledige breedte" variant enkel indien deze layout te smal is om alle content duidelijk te visualiseren.

<details open>
    <summary>Code</summary>
    <Source
        language="html"
        dark
        format={true}
        code={`
<html>
    <body>
        <vl-page>
            <vl-header-next slot="header" skip-to-content-id="main-content"></vl-header-next>
            <div slot="main">
                <vl-functional-header title="Page Layout" skip-to-content-id="#main-content">...</vl-functional-header>
                <section class="vl-section">
                    <div class="vl-content-block">
                        <vl-title type="h1" id="main-content">Content</vl-title>
                    </div>
                </section>
            </div>
            <vl-footer-next slot="footer"></vl-footer-next>
        </vl-page>
    </body>
</html>
        `}
    ></Source>
</details>

## Volledige breedte

Dit is een layout voor applicaties die de volledige schermbreedte nodig hebben. Gebruik dit enkel wanneer de standaard layout niet mogelijk is, bijvoorbeeld in het geval van uitgebreide data tabellen.

Voeg hiervoor de volgende attributen toe:

- `full-width` op het `<vl-functional-header>` component
- de class `vl-content-block--full-width` op alle content blokken

<details open>
    <summary>Code</summary>
    <Source
        language="html"
        dark
        format={true}
        code={`
<html>
    <body>
        <vl-page>
            <vl-header-next slot="header" skip-to-content-id="main-content"></vl-header-next>
            <div slot="main">
                <vl-functional-header title="Page Layout" full-width skip-to-content-id="#main-content">...</vl-functional-header>
                <section class="vl-section">
                    <div class="vl-content-block vl-content-block--full-width">
                        <vl-title type="h1" id="main-content">Content</vl-title>
                    </div>
                </section>
            </div>
            <vl-footer-next slot="footer"></vl-footer-next>
        </vl-page>
    </body>
</html>
        `}
    ></Source>
</details>
