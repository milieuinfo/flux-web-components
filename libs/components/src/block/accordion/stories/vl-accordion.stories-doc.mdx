## Doel

Gebruik de `accordion` component om informatie te tonen of te verbergen aan de hand van een toggle.
Voor meer informatie over het afbeelden van meerdere accordions zie de
[accordion-list](/docs/components-block-accordion-list--documentatie) component.


## Voorbeeld

```js
import { VlAccordionComponent } from '@domg-wc/components/block';
```

## Toegankelijkheid

De inhoud van een gesloten accordion blijft vindbaar via de zoekfunctie van de browser (Ctrl+F of Cmd+F). Vindt de
browser een resultaat in die inhoud, dan klapt de accordion open en wordt het `vl-on-toggle` event afgevuurd. Hetzelfde
gebeurt bij een link naar een `id` in de inhoud.

Een accordion met het `disabled` attribuut blijft gesloten, en zijn inhoud is niet vindbaar.
