# Steps

<FluxComponentMetaData id="components-block-steps-steps" />


## Doel

Gebruik de `steps` component om een verticale lijst van stappen af te beelden om de gebruiker door een procedure te
begeleiden.<br/>

Deze component is de nieuwe versie van de [vl-steps](/docs/components-block-steps--documentatie) component, we raden aan deze versie te gebruiken.


## Voorbeeld

```js
import { VlStepsComponent } from '@domg-wc/components/block';
```

```html
<vl-steps></vl-steps>
```

### Tijdlijn

#### vl-duration-step

Een `<vl-duration-step>` moet je zien als een onderdeel van een `<vl-step>` en hoort dus in een eigen `<ul>` lijst
element te staan. Plaats hem daarvoor in de `<vl-step>` met het slot "duration".

```html
<vl-step>
    ...
    <vl-duration-step slot="duration">...</vl-duration-step>
</vl-step>
```
<Canvas of={VlStepsStories.StepsTimeline} />

##### Interactieve tijdlijn

Standaard heeft elke `<vl-duration-step>` een zwarte stip. Zijn de stappen navigeerbaar (bijvoorbeeld
links naar een eerdere toestand), markeer ze dan met het `interactive`-attribuut: hun stip krijgt de
actie-kleur, net zoals een link. De huidige stap markeer je met `selected`: die houdt een zwarte stip en
krijgt `aria-current="true"`. Zet in die stap platte tekst, geen link: je bent er al, dus een link naar de
huidige toestand is misleidend voor toetsenbord- en screenreadergebruikers (WCAG). `selected` wint wel van
`interactive`, dus mocht een stap toch beide hebben, dan blijft ze zwart.

`interactive` kleurt enkel de stip; de klikbaarheid komt van de link of knop die je in de stap zet, niet
van het attribuut. Gebruik het dus enkel op stappen die echt een link of knop bevatten, anders suggereert
de blauwe stip klikbaarheid die er niet is. Een screenreader leidt de interactiviteit af uit die link, niet
uit de kleur.

<Canvas of={VlStepsStories.StepsTimelineInteractive} />

De stip zit in de shadow DOM en is via `::part(duration-step)` ontsloten (de stip zelf is het `::after`).
Zo pas je als afnemer de stip aan:

```css
vl-duration-step[interactive]::part(duration-step)::after {
    background-color: var(--vl-color--action-hover);
}
```

## Toegankelijkheid

### icon-aria-label en timeline-aria-label

Bij het gebruik van de "iconen" of "tijdlijn" varianten is het aangeraden om respectievelijk de attributen 
`icon-aria-label` en `timeline-aria-label` in te vullen op het `<vl-step>`-component. Dit kan een label voor het icoon 
of de volledige datum bevatten.

### heading-level

Om de logische volgorde van de pagina headings te respecteren kan je een `heading-level` meegeven. Hiermee kan je ipv
de standaard `<h3>`-heading, `<h1>` tot `<h6>` laten renderen.

### aria-current

Een `<vl-duration-step>` met het `selected`-attribuut krijgt `aria-current="true"`, zodat een screenreader de
geselecteerde toestand herkent.
