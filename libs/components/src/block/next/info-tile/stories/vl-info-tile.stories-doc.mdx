## Doel

Gebruik de `info-tile-next` component in informatieve en interactieve dashboards.

Deze component is de nieuwe versie van de [vl-info-tile](/docs/components-block-info-tile--documentatie) component.


## Voorbeeld

```js
import { VlInfoTileComponent } from '@domg-wc/components/block/next';
```

```html
<vl-info-tile-next>
    <span slot="trigger">Titel</span>
    <div slot="content">Inhoud</div>
</vl-info-tile-next>
```

## Open en sluiten

Bij een `toggleable` info tile zet het `open` attribuut de begintoestand en volgt het daarna de huidige toestand. Je kan
het lezen en zetten, of de methodes `show()`, `hide()` en `toggle()` gebruiken.

Bij elke wijziging van de open-toestand worden `vl-toggle` (met `{ expanded }`) en daarna `vl-open` of `vl-close`
afgevuurd. Die events bubbelen.


## Styling

De component toont zijn onderdelen via `::part()`: `base` (krijgt ook `expanded` als de info tile open is), `header`,
`trigger` (enkel bij `toggleable`), `icon`, `subtitle`, `content`, `actions` en `footer`.

De achtergrondkleur, randkleur en iconkleur van de icon badge zijn aanpasbaar via CSS variabelen.

- **`--vl-info-tile-icon-background-color`**: de achtergrondkleur van de icon badge.
- **`--vl-info-tile-icon-border-color`**: de randkleur van de icon badge.
- **`--vl-info-tile-icon-color`**: de kleur van het icoon zelf.

## Toegankelijkheid

De inhoud van een gesloten `toggleable` info tile blijft vindbaar via de zoekfunctie van de browser (Ctrl+F of Cmd+F).
Vindt de browser een resultaat in die inhoud, dan klapt de info tile open. Hetzelfde gebeurt bij een link naar een `id`
in de inhoud.


## Migratie van vl-info-tile

| vl-info-tile | vl-info-tile-next |
| --- | --- |
| `auto-open` | `open` |
| slot `title` | slot `trigger` |
| slot `menu` | slot `actions` |
| `isOpen` | `open` |
| `open()` en `close()` | `show()` en `hide()` |
| `custom-css` op klassen in de shadow DOM | `::part()` en `vl-info-tile-next[open]` |
