# Tabs Next

<FluxComponentMetaData id="components-block-next-tabs" />

## Doel

Gebruik deze component om content op te delen in verschillende tabbladen.

Dit component heeft twee varianten:

- **Standaard tabs patroon**:
    - Deze variant wordt best gebruikt als **widget op een pagina** en niet als navigatie element.
    - Deze implementatie volgt de [ARIA tab patroon richtlijnen](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) voor `role="tablist"`.
    - De tabs zijn bedienbaar met de pijltjestoetsen.
    - De tabpanelen worden allemaal gerenderd, maar enkel het selecteerde tabpaneel wordt getoond.
    - Bij deze variant gebruik je de `<vl-tab-next>` als tab elementen en de `<vl-tab-panel-next>` als tabpanelen.
- **Horizontale navigatie**:
    - Deze variant implementeert geen `role="tablist"` maar doet dienst als **navigatie element**.
    - Bij deze variant gebruik je de `<vl-tab-link-next>` als tab elementen.

## Op een smal scherm

Op een scherm tot 767px breed, en dus ook op een sterk ingezoomde pagina, toont `vl-tabs-next` in de plaats van de tabs een knop met de naam van de geselecteerde tab. Die knop opent een lijst met alle tabs. Tabs die je na het laden toevoegt of verwijdert, bijvoorbeeld na een `fetch`, volgt de lijst mee. Een `external` tab link meldt ook in de lijst dat hij in een nieuw venster opent.

Bij horizontale navigatie zet je `selected` op de `<vl-tab-link-next>` van de huidige pagina wanneer je de links rendert: de knop toont dan meteen die link. Komen de links pas na het laden binnen zonder `selected`, dan selecteert `vl-tabs-next` op een smal scherm de eerste. Zet je `selected` pas daarna op een andere link, dan zijn er twee links geselecteerd en blijft de knop de eerste tonen: zet `selected` daarom mee op het moment dat je de links toevoegt. Verplaats je `selected` later zelf naar een andere link, bijvoorbeeld bij een paginawissel in een single-page app, haal het dan ook weg bij de vorige. De knop en de lijst tonen zo'n verplaatste `selected`, of een gewijzigde tekst van een tab, pas wanneer de gebruiker de lijst opent.

Met het toetsenbord opent of sluit Enter of Spatie op de knop de lijst. Bij het openen staat de focus op de geselecteerde tab. De pijltjestoetsen omhoog en omlaag, Home en End verplaatsen de focus, ook vanaf de knop zolang de lijst open is. Enter of Spatie kiest de tab waar de focus op staat, ook als je er met Tab naartoe ging, en Escape sluit de lijst. Daarna staat de focus weer op de knop. Bij een keuze, met het toetsenbord of met een klik, gaat de focus al vóór `vl-tab-change` naar de knop en sluit de lijst: weigert een listener de keuze, dan blijft de focus daar, en een modal die de listener opent, houdt de focus. `vl-modal-next` zet ze bij het sluiten terug op de knop. Bij het heropenen start de lijst op de tab die geselecteerd bleef.

## Een tabwissel weigeren

Voor de gebruiker naar een andere tab wisselt, vuurt `vl-tabs-next` het cancelable event `vl-tab-change`. Dat gebeurt bij een klik, Enter of Spatie, de pijltjestoetsen, Home en End, en bij een keuze in de lijst op een smal scherm. Roep `preventDefault()` aan om de wissel te weigeren, bijvoorbeeld als een formulier in de huidige tab niet-bewaarde wijzigingen heeft. De huidige tab blijft dan geselecteerd, het zichtbare tabpaneel verandert niet en een `<vl-tab-link-next>` navigeert niet naar zijn `href`.

- `event.detail.tab` is de tab die de gebruiker wil openen, `event.detail.previousTab` de tab die nu geselecteerd is.
- Het event vuurt enkel bij een echte wissel: niet bij een klik op de geselecteerde tab en niet bij een programmatische selectie met `select()`. Bij een klik met Ctrl, Cmd, Shift of Alt op een tab link volgt de browser zijn eigen gedrag, zoals openen in een nieuw tabblad: de tab wordt dan niet geselecteerd en het event vuurt niet.
- Beslis synchroon in de listener. Wil je eerst een bevestiging vragen, weiger de wissel dan en roep na de bevestiging `select()` aan op `event.detail.tab`. Een `<vl-tab-link-next>` volgt daarbij zijn link zoals bij een klik, met `external` in een nieuw venster. Roep `select()` voor een `external` link kort na een actie van de gebruiker aan, zoals de klik op de bevestigingsknop: na een trage stap ertussen, zoals een `fetch`, kan de popup-blocker van de browser het nieuwe venster tegenhouden.
- `vl-tab-click` en `vl-tab-link-click` vuren ook als de wissel geweigerd wordt, en ook bij `select()`. Reken niet op hun volgorde ten opzichte van `vl-tab-change`. `preventDefault()` heeft op die events geen effect. Doe routering in een single-page app daarom in de listener van `vl-tab-change`. Omdat `select()` dat event niet vuurt, routeer je na een bevestiging ook zelf, bij je aanroep van `select()`.
- Geef de gebruiker zichtbare feedback die ook voorgelezen wordt, bijvoorbeeld met een modal of een alert. Anders lijkt het voor toetsenbord- en screenreadergebruikers alsof de tabs niet reageren. Bij een pijltjestoets, Home of End zet `vl-tabs-next` de focus vóór het event op de tab die de gebruiker wil openen, en laat die daar ook bij een weigering. Zo kan een toetsenbordgebruiker de tabs verder doorlopen, en houdt een modal die je in de listener opent de focus. Op een smal scherm staat de focus vóór het event op de knop van de lijst (zie "Op een smal scherm").

```js
const tabs = document.querySelector('vl-tabs-next');

tabs.addEventListener('vl-tab-change', (event) => {
    if (heeftNietBewaardeWijzigingen()) {
        event.preventDefault();
        vraagBevestiging().then((bevestigd) => {
            if (bevestigd) {
                event.detail.tab.select();
            }
        });
    }
});
```

## Varianten

### Horizontale navigatie

Zet `horizontal-navigation` op `vl-tabs-next`, gebruik `<vl-tab-link-next>` als tab elementen en zet `selected` op de link van de huidige pagina. Op een breed scherm maakt `vl-tabs-next` van de links een lijst voor schermlezers, ook van links die je na het laden toevoegt.

```js
import { VlTabsComponent, VlTabLinkComponent } from '@domg-wc/components/block/next';
```

```html
<vl-tabs-next horizontal-navigation label="Mijn navigatie">
    <vl-tab-link-next href="#tab1" selected>Trein</vl-tab-link-next>
    <vl-tab-link-next href="#tab2">Metro, tram en bus</vl-tab-link-next>
    <vl-tab-link-next
        href="https://www.vlaanderen.be/intern/werkplek/dienstreizen-en-woon-werkverkeer/vervoersmiddelen/fietsen"
        external
        >Fiets</vl-tab-link-next
    >
</vl-tabs-next>
```
