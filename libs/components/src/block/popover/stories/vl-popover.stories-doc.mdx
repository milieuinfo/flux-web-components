# Popover

<FluxComponentMetaData id="components-block-popover" />


## Doel

Een popover is een nieuw, meestal kleiner venster / popup dat boven de andere inhoud op het scherm verschijnt.
Het doel van de popover is het bouwen van context- of submenu's. Je kan deze menu's opbouwen a.d.h.v. de
`vl-popover-action-list` en `vl-popover-action` componenten. De popover kan ook andere interactieve HTML-elementen
bevatten.


## Voorbeeld

```js
import { VlPopoverComponent } from '@domg-wc/components/block';
```

```html
<vl-button id="popover-trigger"></vl-button>
<vl-popover for="popover-trigger"></vl-popover>
```

## Gebruik

### Standaard pijl & afstand

Standaard wordt:
- de pijl getoond (je kan de pijl verbergen met `hide-arrow`)
- wordt de `distance` ingesteld op `10px`

### Oriëntatie
> [Raadpleeg de placement documentatie van floating-ui](https://floating-ui.com/docs/tutorial#placements)

Je kan de oriëntatie bepalen van de popover als daarvoor plaats is met `placement`. Als er niet genoeg ruimte is zal `floating-ui` achterliggend een alternatieve oriëntatie kiezen.

Je kan een `-start` of `-end` suffix toevoegen zodat de oriëntatie start of eindigt aan respectievelijk het begin of einde van het referentie-element.

### Strategy
> [Raadpleeg de strategy documentatie van floating-ui](https://floating-ui.com/docs/computePosition#strategy)

Standaard is `strategy` ingesteld op `absolute`. De popover zal gepositioneerd worden ten opzichte van het
dichtstbijzijnde gepositioneerde parent-element (bv. een element met `position: relative`).

Om te vermijden dat de popover gepositioneerd wordt tegenover het verkeerde element, kan je best de eerste parent van de popover instellen op `position: relative` zodat de popover steeds gepositioneerd wordt zoals verwacht.

## Varianten

### Hover / Tooltip

Je kan de standaard `click` waarde voor `trigger` combineren met `hover`: `trigger="click hover"`. De popover opent dan
bij hover en bij een klik, en dus ook met Enter of Spatie op de trigger. Een klik op een popover die net door hover
openging, laat hem open. Bevat de popover acties of andere interactieve inhoud, gebruik dan liefst enkel `click`.

Gebruik `hover` **nooit alleen**. Met enkel `trigger="hover"` kan je de popover niet openen met het toetsenbord of een
schermlezer (WCAG 2.1.1 en 1.4.13).

Het gebruik van het vl-popover component als tooltip is **deprecated**. Gebruik voor tekst zonder interactie het
[vl-tooltip](/docs/components-block-tooltip--documentatie) component.

### Popover Actions

Je kan een lijst van acties toevoegen aan de popover en een actie markeren als het huidige item met `selected`, bv. de
huidige pagina of de laatst gekozen weergave. Een schermlezer leest dat via `aria-current`.

    </vl-popover-action-list>
    `} language="html" dark={true} />
</details>
<details>
    <summary>Toon TypeScript code voorbeeld</summary>
    <Source code={`
    const actionListClickHandler = (event: CustomEvent) => {
            const actionElement = event.target as VlPopoverActionComponent;
            const allActions = Array.from(actionElement.parentElement?.querySelectorAll('vl-popover-action') || []);
            allActions.forEach((action) => {
                if (action !== actionElement) {
                    action.removeAttribute('selected');
                }
            });
            actionElement.setAttribute('selected', '');
        };
    `} language="ts" dark={true} />
</details>

## Toegankelijkheid

De popover werkt als een disclosure: een knop die een groep met acties toont of verbergt. Het is geen ARIA-menu.

Dat is een bewuste keuze. Een ARIA-menu belooft het toetsenbordgedrag van een applicatiemenu (pijltoetsen, Home en End,
één tabstop), terwijl een popover vaak links en andere inhoud bevat. Voor navigatie raadt het APG een disclosure aan
([Disclosure Navigation Menu](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)).
Voeg daarom zelf geen `role="menu"` of `role="menuitem"` toe.

- De trigger krijgt `aria-expanded` en `aria-controls`. Zet de `vl-popover` in de DOM direct na de trigger, zodat de
  volgorde met Tab klopt.
- De acties zijn gewone knoppen en links. Je gaat ernaar met Tab, niet met de pijltoetsen.
- Escape sluit de popover. Stond de focus in de popover, dan gaat ze terug naar de trigger. Dat gebeurt ook wanneer een
  actie de popover sluit met `hide-on-click`, tenzij je eigen click-handler de focus al elders zette, bv. in een modal.
- Opende de popover door hover, dan sluit Escape hem ook als de focus ergens anders staat.
- Verlaat de focus de popover met Tab of Shift+Tab, ook terug naar de trigger, dan sluit hij.
- Een `vl-popover-action` met `href` blijft een link.
- Geef de `vl-popover-action-list` eventueel een `aria-label`, bv. `aria-label="Acties"`.
