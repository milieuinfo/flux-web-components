# Data source

<FluxComponentMetaData id="data-visualisation-data-source" />

## Doel

`vl-data-source` haalt de data op voor de figuren en grafieken erin, zodat ze dezelfde periode tonen. De component zelf
is onzichtbaar. Met een [vl-data-period](/docs/data-visualisation-data-period--documentatie) kiest de gebruiker een
andere periode.

## Voorbeeld

```js
import { VlChartLine, VlDataFigure, VlDataPeriod, VlDataSource } from '@domg-wc/widgets/datavis';
```

```html
<vl-data-source src="https://example.org/FROST-Server/v1.1/Things(1)" period="24h">
    <vl-data-figure headline="Magnetische veldsterkte">
        <vl-data-period></vl-data-period>
        <vl-chart-line></vl-chart-line>
    </vl-data-figure>
</vl-data-source>
```

## Varianten

### SensorThings (standaard)

`format="sensorthings"` leest een [SensorThings API](https://docs.ogc.org/is/18-088/18-088.html), zoals FROST. `src`
is één meetpunt (`…/Things(1)`) of één meetreeks (`…/Datastreams(1)`). Elke meetreeks met getallen wordt een lijn.

De `metadataId` is de UUID van de record in de [metadatacatalogus](https://metadata.omgeving.vlaanderen.be), niet die
van de dataset. De grafiek haalt er de titel, de eigenaar en de licentie uit.

### Voorbeelddata

`format="sample-data"` leest een ChartModel in JSON, voor een webapp zonder echte data, stories en tests. De component
vraagt `src?from=…&to=…`; een statisch bestand toont dus elke periode dezelfde data.

```json
{
    "meta": {
        "sources": [{ "metadataId": "1fe4dff9-87b4-5646-b29a-a026025f520e" }],
        "x": { "type": "time" },
        "y": { "type": "number", "title": "Magnetische veldsterkte", "unit": "µT" }
    },
    "series": [
        {
            "name": "Temse",
            "x": ["2026-11-04T09:00:00+01:00", "2026-11-04T09:10:00+01:00", "2026-11-04T09:20:00+01:00"],
            "y": [0.331, null, 0.298]
        }
    ]
}
```

`x` is een ISO 8601-tijdstip of een aantal milliseconden. `null` onderbreekt de lijn.

## Gedrag

- De component haalt het meetpunt één keer op, en per periode de metingen van elke meetreeks.
- Tijdens het laden houden de grafiek en de controls hun plaats, zodat de pagina niet verspringt.
- Is de bron niet bereikbaar, of hebben de meetreeksen een andere eenheid, dan toont de grafiek een melding.
