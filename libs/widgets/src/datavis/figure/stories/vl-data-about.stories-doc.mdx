# Data about

<FluxComponentMetaData id="data-visualisation-data-about" />

## Doel

`vl-data-about` toont "Over deze data" onder de grafiek van een [vl-data-figure](/docs/data-visualisation-data-figure--documentatie): de bron, de eenheid en open data, uit `meta`.
Eigen tekst in de component staat eronder.

## Voorbeeld

```js
import { VlDataAbout } from '@domg-wc/widgets/datavis';
```

```html
<vl-data-figure headline="In Gent en Antwerpen daalt de concentratie sinds 2020">
    <vl-chart-line></vl-chart-line>
    <vl-data-about>
        <p>De meetpunten staan langs drukke wegen. Ze tonen de hoogste concentraties in de stad.</p>
    </vl-data-about>
</vl-data-figure>
```

## Varianten

### Twee bronnen

Met enkel een `metadataId` per bron haalt de component de titel, eigenaar en licentie uit de
[metadatacatalogus](https://metadata.omgeving.vlaanderen.be). De bronnen zijn echte records, de cijfers fictief.

- Bij meer bronnen krijgt elke bron een genummerde lijst. Eenheid en open data gelden voor de hele figuur; de figuur
  is enkel open data als alle bronnen het zijn.
- Zonder eigen `vl-data-about` voegt de figuur er een toe als een bron een `metadataId`, `license` of `dataHref` heeft.
- De gegevens staan in een `<dl>`, zodat een schermlezer bij elke waarde de term voorleest.
