# Data visualisation

Bouwstenen om meetdata als grafiek te tonen, op een consistente en toegankelijke manier en op basis van de
Flux-componenten. Je nest drie lagen: **source → figure → chart**.

## Voorbeeld

```js
import { VlChartLine, VlDataFigure, VlDataPeriod, VlDataSource } from '@domg-wc/widgets/datavis';
```

```html
<vl-data-source src="https://example.org/FROST-Server/v1.1/Things(1)" period="24h">
    <vl-data-figure headline="Magnetische veldsterkte" subtitle="Temse, sensor ELF_L_0004, 380 kV">
        <vl-data-period></vl-data-period>
        <vl-chart-line></vl-chart-line>
    </vl-data-figure>
</vl-data-source>
```

## Afspraken

- **Jij schrijft de tekst**: de `headline`, de ondertitel en de uitleg. De figuur zorgt voor de Flux-opmaak.
- **De tabel is verplicht.** Ze is het tekstalternatief van de grafiek.
- **De opbouw ligt vast**: kop met controls, filters, grafiek, tabel en uitleg.
- **De waarde-as bevat altijd 0.**
